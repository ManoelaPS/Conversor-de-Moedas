# Conversor de Moedas

## 📌 Sobre o Projeto
Aplicação em Java desenvolvida para realizar conversões entre o **Real (BRL)** e moedas estrangeiras (**Dólar, Euro, Iene e Peso Mexicano**).

O grande foco desta versão foi refatorar a estrutura do projeto para seguir o padrão **MVC (Model-View-Controller)**, dividindo as responsabilidades do código:

* `br.com.modelo`: Regras de negócio e fórmulas de conversão (`Moeda` e `Calculo`).
* `br.com.controle`: Ponte de comunicação (`Moedacontrole`).
* `br.com.visao`: Interface gráfica Swing (`Tela`).

> *Layout visual inspirado em tutorial do YouTube, com toda a lógica, refatoração em MVC e organização feitas por mim.*

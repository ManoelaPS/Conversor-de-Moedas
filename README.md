# Conversor de Moedas

## 📌 Sobre o Projeto
Aplicação em Java desenvolvida no NetBeans para conversão entre o **Real (BRL)** e moedas estrangeiras (**Dólar, Euro, Iene e Peso Mexicano**).

### Destaques Técnicos:

* **Organização em Pacotes:** Separação da interface (br.com.visao) e regras de conversão (br.com.controle).
* **Conceitos Aplicados:** Encapsulamento, estruturas switch-case e validação de dados com JOptionPane.

> *Layout visual inspirado em tutorial do YouTube, com regras de negócio e estrutura organizadas por mim.*

---

## Tecnologias
* **Linguagem:** Java
* **Interface:** Java Swing
* **IDE:** NetBeans IDE
